# QQ 转发客户端 功能清单

## 一、总览

| 分类 | 模块数 | 说明 |
|---|---|---|
| 消息自动化 | 4 | 转发、定时、关键词、飞书 |
| 群运营 | 4 | 公告、成员、禁言精华、活跃度 |
| 数据与日志 | 2 | 转发记录、运行日志 |
| 系统 | 1 | 配置、备份、激活 |
| 基础能力 | — | 账号连接、激活授权 |

---

## 二、基础能力

### 2.1 QQ 账号连接

| 功能 | 说明 |
|---|---|
| 自动识别进程 | 启动时自动检测已登录的电脑版 QQ |
| 一键加载 | 选择进程后点击加载，自动挂接 |
| 账号信息探测 | 显示 QQ 号、昵称、是否已登录 |
| 连接状态监控 | 实时显示在线/离线状态 |
| 一键修复连接 | 换号或异常时清理旧配置并重启服务 |
| 自动清理旧账号配置 | 启动时清理非当前账号的适配器配置，避免端口冲突 |

---

## 三、消息自动化

### 3.1 消息转发

| 功能 | 说明 |
|---|---|
| 多源群 → 多目标群 | 一条规则可配置多个源群和多个目标群 |
| 转发到好友 | 目标可以是群，也可以是好友私聊 |
| 关键词过滤 | 只转发包含指定词的消息 |
| 关键词排除 | 包含指定词的消息不转发 |
| 媒体类型开关 | 单独控制图片、视频、语音、文件的转发 |
| @ 消息转发 | 可控制是否保留 @ 提醒 |
| 身份标识 | 在消息前后添加来源标记，格式可自定义 |
| 自身消息转发 | 可控制是否转发自己发的消息 |
| 转发去重 | 同一条消息不重复转发（防断线重连重推） |
| 合并转发拆分 | 聊天记录卡片自动拆成独立消息逐条发送 |
| 媒体直链转换 | 群文件自动换取下载链接后转发 |
| 失败隔离 | 单个目标失败不影响其他目标 |

### 3.2 定时发送

| 功能 | 说明 |
|---|---|
| 单次执行 | 指定日期时间发一次 |
| 间隔执行 | 每隔 N 秒/分/小时重复发送 |
| 每日定时 | 每天固定时间发送 |
| 发送到群 | 支持多选群 |
| 发送到好友 | 支持多选好友 |
| 文本内容 | 支持换行、CQ 码（如表情） |
| 图片附件 | 最多 9 张，自动随文本发送 |
| 视频附件 | 支持，独占单条消息发送 |
| 文件附件 | 支持，显示为可下载文件 |
| 发送间隔 | 0-60000ms 可调，附加 0~30% 随机抖动 |
| 消息预览 | 实时模拟聊天界面展示最终效果 |
| 发送后回读校验 | 可选，发送后核对群消息确认投递 |
| 测试发送 | 编辑时先发一次看效果，不走定时逻辑 |
| 任务开关 | 单独启用/停用 |
| 运行统计 | 记录执行次数、上次执行时间 |

### 3.3 关键词回复

| 功能 | 说明 |
|---|---|
| 关键词触发 | 命中任意关键词即回复 |
| 任意消息触发 | 不设关键词，收到消息就回复 |
| 匹配模式 | 模糊（包含即触发）/ 精确（完全一致） |
| 生效场景 | 全部 / 仅私聊 / 仅群聊 |
| 限定群 | 只在指定群生效 |
| 冷却时间 | 同会话内 N 秒只回复一次，防止刷屏 |
| 回复文本 | 支持换行、CQ 码 |
| 回复图片 | 支持多张 |
| 回复视频 | 支持 |
| 回复文件 | 支持 |
| 消息预览 | 实时预览对方看到的效果 |
| 继续匹配开关 | 回复后是否继续检查后续规则 |
| 规则排序 | 支持上下调整优先级 |
| 规则开关 | 单独启用/停用 |
| 防循环 | 不会回复自己发的消息（可配置） |

### 3.4 飞书转发

| 功能 | 说明 |
|---|---|
| QQ 群 → 飞书群 | 将 QQ 消息同步到飞书 |
| Webhook 管理 | 支持多 Webhook，带备注 |
| 关键词过滤 | 只同步包含指定词的消息 |
| 媒体类型开关 | 控制图片等是否同步 |
| 消息合并 | 多条消息合并为一条富文本发送 |
| 应用凭证配置 | 支持自建应用上传图片，未配置时降级为链接 |
| 失败重试 | 429 限流自动重试 |
| 失败提示 | 提示具体规则名和失败数量 |

## 四、群运营

> 需要当前账号是该群的群主或管理员，非管理员时相关按钮自动禁用。

### 4.1 群公告

| 功能 | 说明 |
|---|---|
| 多群同时发布 | 一条公告发到多个群，支持搜索和全选 |
| 置顶开关 | 公告是否置顶显示 |
| 群间间隔 | 可调 0-30 秒，降低被拦截概率 |
| 发送结果统计 | 显示总计/成功/失败数量 |
| 失败明细 | 逐个列出失败的群和原因（错误码翻译为中文） |
| 查看已有公告 | 查看指定群现有公告列表 |
| 删除公告 | 删除指定公告 |

### 4.2 群成员

| 功能 | 说明 |
|---|---|
| 成员列表 | 展示头像、昵称、群名片、QQ 号、身份、加群时间 |
| 搜索 | 按昵称 / QQ 号 / 群名片搜索 |
| 身份筛选 | 全部 / 仅群主 / 仅管理员 / 仅普通成员 |
| 统计概览 | 总成员、群主与管理員数量、筛选结果、非好友数 |
| 非好友标记 | 自动标记不在好友列表的成员 |
| 导出 CSV | 导出筛选结果为 Excel 可直接打开的表格 |
| 复制 QQ 号 | 一键复制所有成员 QQ 号 |
| 戳一戳 | 提醒指定成员 |
| 禁言 | 可选 10 分钟 / 1 小时 / 1 天 / 30 天 |
| 踢出 | 移出群聊 |
| 分页 | 每页 20 条 |

### 4.3 禁言与精华

| 功能 | 说明 |
|---|---|
| 全员禁言 | 开关控制，所有成员无法发言 |
| 禁言列表 | 查看当前被禁言成员及剩余时长 |
| 解除禁言 | 一键解除指定成员禁言 |
| 精华消息列表 | 查看群内所有精华消息 |
| 设为精华 | 将指定消息设为精华 |
| 撤回消息 | 撤回 2 分钟内的消息 |
| 最近消息 | 展示最近 20 条消息，可设精华/撤回 |
| 权限预检 | 非管理员时禁用相关操作并提示原因 |

### 4.4 群活跃度

| 功能 | 说明 |
|---|---|
| 采样分析 | 可选最近 50 / 100 / 200 条消息 |
| 概览指标 | 采样消息数、发言人数、人均发言、最活跃时段 |
| 活跃排行 | TOP 10 成员，含发言条数与条形图 |
| 潜水成员 | 统计该时段未发言的成员，可复制 QQ 号 |
| 时段分布 | 24 小时发言量柱状图 |
| 群主排除 | 群主不计入潜水名单 |

## 五、数据与日志

### 5.1 转发记录

| 功能 | 说明 |
|---|---|
| 分类查看 | 消息转发 / 定时发送 / 关键词回复 / 飞书转发 |
| 执行统计 | 今日与累计成功/失败数量 |
| 记录详情 | 规则名、源群、目标群、消息摘要、时间 |
| 状态标记 | 成功（绿）/ 失败（红）/ 待确认（黄） |
| 错误原因 | 失败记录显示具体原因（中文） |
| 分页浏览 | 支持翻页 |
| 清空记录 | 按类型清空历史 |

### 5.2 运行日志

| 功能 | 说明 |
|---|---|
| 实时日志流 | 展示客户端与运行时的日志 |
| 关键词搜索 | 按关键字筛选 |
| 自动滚动 | 新日志自动滚到底部 |
| 日志存储状态 | 显示日志占用空间与文件数 |
| 自动清理 | 超过设定大小或天数自动清理 |
| 手动清空 | 一键清空所有日志 |

## 六、系统配置

### 6.1 通用设置

| 功能 | 说明 |
|---|---|
| 开机自启动 | 开机后自动运行软件 |

### 6.2 备份与恢复

| 功能 | 说明 |
|---|---|
| 导出备份 | 将全部规则打包为单个 JSON 文件 |
| 自选保存路径 | 通过系统对话框选择位置 |
| 自动打开文件夹 | 导出完成后自动定位到该文件 |
| 文件名校验 | 自动附带日期，便于区分 |
| 导入恢复 | 通过系统对话框选择文件，校验后恢复 |
| 覆盖提示 | 恢复前二次确认，提示会覆盖现有规则 |
| 恢复内容 | 转发规则、定时任务、关键词回复、飞书规则与配置 |

### 6.3 激活信息

| 功能 | 说明 |
|---|---|
| 激活状态 | 显示已激活/未激活 |
| 授权时长 | 显示永久/剩余天数 |
| 激活时间 | 显示首次激活时间 |
| 到期时间 | 显示授权到期日 |
| 机器码 | 显示本机机器码，便于售后服务 |

### 6.4 界面

| 功能 | 说明 |
|---|---|
| 亮色/暗色主题 | 一键切换，自动记忆 |
| 响应式布局 | 适配不同分辨率屏幕 |
| 侧边栏分组 | 五组分类导航 |
| 窗口最大化 | 启动默认最大化，可还原为 1500×800 |
