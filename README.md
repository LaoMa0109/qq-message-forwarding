# qq-message-forwarding
运行在 Windows 上的 QQ 消息自动化工具，挂接你已登录的电脑版 QQ 即可工作。核心是把重复操作变自动：
**消息转发**可将多个群的消息同步到多个群或好友，支持关键词过滤和分类开关；
**定时发送**支持一次性、间隔、每日定时三种模式，能发文字图片视频文件，多群可调间隔避免被拦；
**关键词回复**支持别人发指定词自动回复，可限定场景并设置冷却防刷屏。
面向管理者提供
**群公告**一键发多群、
**群成员**查看筛选导出名单、
**禁言与精华**管理禁言与撤回、
**群活跃度**分析谁活跃谁潜水。
另有
**飞书转发**同步到飞书群、
**转发记录**查看结果、
**运行日志**排查问题、
**配置备份**一键导出导入规则方便换电脑。
